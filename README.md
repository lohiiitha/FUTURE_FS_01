## 📌 Overview

This project is a fully responsive portfolio website designed to present my work and profile in a structured and visually appealing manner. It serves as a digital resume and a central place to explore my projects.

---

## 🚀 Features

- 📱 Fully responsive design (mobile + desktop)
- 🎨 Clean and modern UI
- 📂 Projects showcase section
- 🧠 Skills section
- 📞 Contact section
- 🌙 Smooth scrolling and interactive elements

---

## 🛠️ Tech Stack

- **HTML5** – Structure of the website  
- **CSS3** – Styling and layout (Flexbox/Grid)  
- **JavaScript** – Interactivity and dynamic behavior
